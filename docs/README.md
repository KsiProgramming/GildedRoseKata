# Documentation

This repository contains a solution to the Gilded Rose kata in .NET. It has a core library with the legacy inventory-update code and a refactored, domain-modelled version that supports Conjured items. It also has an xUnit test project for the refactored code.

## Index

- [src-Core.md](src-Core.md): `src/Core`, the core library with the original `UpdateQuality` code and the refactored `ProposedCode` maturing rules.
- [tests-Core.Tests.md](tests-Core.Tests.md): `tests/Core.Tests`, the xUnit tests for the `ProposedCode` implementation.
