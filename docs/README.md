# Documentation

This repository contains the Gilded Rose kata in C# (.NET). It keeps the legacy "update quality" implementation next to a refactored, domain-modelled version, and has an xUnit test project for the refactored code.

## Index

- [src/Core](src-Core.md): the class library with the original (`OriginalCode`) and refactored (`ProposedCode`) item quality rules.
- [tests/Core.Tests](tests-Core.Tests.md): the xUnit tests for the refactored domain model, policy and maturation service.
